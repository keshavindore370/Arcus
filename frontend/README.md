# A.R.C.U.S. Web Dashboard (Frontend)

Next.js 14 React client with Tailwind CSS and Cyber HUD styling for the A.R.C.U.S. Phishing and Malicious URL Scanner.

## Features
- **Real-Time URL Scanning**: Instant interactive URL inspection with live progress indicators.
- **Cyber Risk Gauge**: Categorization into Malicious (Red), Suspicious (Yellow), or Benign (Green) with probability score (0-100%).
- **Latency Telemetry**: Proves compliance with the sub-50ms roundtrip specification.
- **Technical Feature Inspector**: Inspects the 20+ lexical features and Shannon entropy computed by Java Spring Boot.
- **MongoDB Audit History**: Interactive historical audit log with clickable past scans.
- **Architecture Viewer**: On-screen interactive modal displaying the four-stage microservice data flow.

## Running Locally
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the scanner dashboard.
